④ 详情：精灵名 / 炫彩名 / 底色 / 顶色 / 粒子，可删除。

这版改了什么

· 粒子点位全站统一：所有色卡都用同一套 3 个点位（左上小 / 中间大 / 右上小），只有形状变——之前小卡片是我画漏了；
· 精灵识别：框住右上角名称牌 OCR（觅觅蝠 / 雪绒鸟），名称牌下面那行当「炫彩名」（炫彩突袭 / 异色炫彩 / 常驻隐藏）；
· 搜索：改成按精灵名 + 炫彩名，不再按色号；
· 展示页卡片显示：精灵名（粗）+ 炫彩名（小）+ 两色色点 + 粒子。

还需要你确认

· 我暂定「炫彩名」= 名称牌下面那行（如「炫彩突袭」「异色炫彩」「常驻隐藏」）。如果它其实是别的东西，告诉我；
· 如果精灵名 OCR 认错，卡片上可以直接改（点开详情改名字）。
