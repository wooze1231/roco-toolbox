四、彩绘「粗糙感」怎么来的（技法拆解）

✗ 之前（太干净，像表单虚线）
设置
深色模式
主题色彩
✓ 现在（抖动墨线 + 蜡笔 + 纸纹）
设置
深色模式
主题色彩
  • ① 抖动墨线：所有描边过 feTurbulence + feDisplacementMap 位移滤镜，直线变波浪、拐角有手绘抖动。
  • ② 蜡笔溢出描边：选中态填充色故意偏移 2–3px 并同样过抖动，颜色「出框」。
  • ③ 纸纹颗粒：整屏叠一层 feTurbulence 噪声（低透明度 multiply），模拟绘本纸齿。
  • ④ 铅笔毛边 + 硬偏移阴影：铅笔墨色描边，不用柔和模糊投影。
  • ⑤ 轻微歪斜：标题/顶栏旋转 ±0.7°，拒绝网格感。
  • ⑥ 手写体（落地时）：标题用中文手写体内置，正文系统字，数值绝不抖动。

六、实现要点（落地时参考）

SettingsActivity.buildAppearanceSection() 主题色彩行（4 选项） 每主题 2 套：light + night（values / values-night） KEY_THEME = gold/candy/paint/ocean 默认 gold 不变
⚠️ Kotlin 硬编码色（Color.WHITE、面板 #FDFCF9、项坠 gold 描边）改随主题资源，否则非米金主题露白/露金；与 Bug A 的 values-night 改造一并做。
⚠️ 彩绘落地难点：原生 View 无现成「抖动滤镜」。靠「手绘不规则圆角 VectorDrawable 背景 + 噪声 PNG 纸纹(multiply) + 偏移选中态 + 手写体(标题)」组合，不靠卡通圆角。
⚠️ 海洋落地：水波用 SVG 矢量波浪背景（顶栏/卡片装饰），主色族走蓝色系；珊瑚橘仅作强调点缀，避免全蓝单调。
⚠️ 四档主题仅换「强调色族 + 底纹/质感」，不动深色模式逻辑（KEY_NIGHT_MODE 独立）。
