操作说明（含本次反馈修正）

① 导入（两步走）：选文件解析成功 → 第一窗口（精简）给「覆盖导入 / 补充导入」两个选项（与导出第一窗口同款白卡片、同字号；覆盖用红字标危险，不整块染红，风格统一）。点任一项 → 第二窗口（详细二次确认）：覆盖写清"替换全部、数量备注蛋数清空、不可恢复、但自动备份可还原"；补充写清"预测新增 N / 跳过 M、不改原有、只加没有的"。第二窗口底部三按钮 返回（回第一窗口重选）/ 取消（整次放弃）/ 确定（执行，覆盖红、补充金）。写盘前都备份 shiny_data.bak.json。

② 导出（全部 / 自选）：点导出 → 第一窗口选「全部赛季 / 自选赛季」。
· 全部 → 标题「导出全部赛季」，只一句话"将导出所有赛季的精灵"，不列 S1–S4 等具体赛季名（赛季数是按当前数据动态读取的，日后有 S5 会自动包含，UI 无需改）；下方一个「包含数量」开关 + 取消 / 导出。
· 自选 → 一行展示 4 个赛季 chip 点选，右侧展开键：赛季 ≤4 时禁用、点了无反应；赛季 >4 时点展开弹出一个大窗口，里面每个赛季是一个小按钮（4 列网格、可多选、可上下滑动、按钮只写「S1/S2…」、不带只数、不写「奇遇」等额外说明），不是列表；大窗口底部同样有「包含数量」开关 + 取消 / 导出。
确认后系统选择器命名保存 shiny_export_<日期>.json，Toast 回路径。导出与导入同 schema，导出文件拿去导入会被自动识别（补充模式显示"新增 0 / 跳过 N"），完全互通。

③ Wiki 悬浮回主页：右下常驻金色按钮，按住拖动换位、点一下 FLAG_ACTIVITY_CLEAR_TOP 回洛克助手主页（清掉 wiki / 图鉴栈）。④⑤ 图鉴底栏：「＋ 告知异色」→「添加图鉴」（去+号）、「截图认字」→「识图添加」、「设置」→「更多」，弹窗标题「告知异色 ·」同步改「添加图鉴 ·」。

③ 赛季数量（使用过程会遇到的事）：赛季是按当前数据动态读的，UI 不写死。
· 1–4 季：自选窗口一行 chip 点选，右侧 ▾ 禁用、点了无反应（没必要弹大窗口）。
· ≥5 季：▾ 启用，点它弹大窗口——4 列小按钮网格（只写 S1/S2…，无奇遇字眼、不带只数），可上下滑动、多选；赛季涨到 20 个也一样，只是窗口更长、滑动更多，不会挤变形。
· 全部赛季：始终按"导出所有赛季"处理，日后有 S5/S20 自动包含，界面不列具体名。

④ 导入异常（使用过程会遇到的事）：
· 选了非 JSON / 缺 seasons 字段的文件 → 红 Toast「文件格式不对·未改动」，不写盘、不备份。
· 补充导入时文件精灵图鉴里全都有 → 扫完预测「新增 0 / 跳过 N」→ Toast「没有可补充的新精灵」，不写盘。

⑤ 备份还原 + 导出差异：每次覆盖/补充导入写盘前都自动备份 shiny_data.bak.json，误覆盖可在设置「还原备份」找回（二次确认）。导出时「包含数量」关→ 文件只有 n/no/s/i；开→ 额外带 c/e/note。两种文件拿去导入都识别（补充模式按"同名/同进化链"判重），完全互通。

⑥ 导入后刷新：覆盖或补充完成后图鉴页自动 re-render，数量、蛋角标照常；本次新增的精灵在预览里以金色框标出（仅示意）。

待确认点：① Wiki 悬浮按钮位置是否记住下次启动（SharedPreferences）；② 数量开关默认关（纯图鉴）是否符合预期；③ 展开键图标用 ▾ 还是别的。
